# Админ зааварчилгаа

## Хэрхэн админ болох

`.env.local`-ийн `ADMIN_PHONES`-д өөрийн дугаараа нэмнэ:

```env
ADMIN_PHONES=99112233,88112233
```

Сервер restart хийгээд тэр дугаараар бүртгүүлбэл шууд админ. Бүртгэгдчихсэн хэрэглэгчийн хувьд нэг удаа re-login хийхэд эрх синк хийгдэнэ.

## Админ console (`/admin`)

```
┌─ Captains ────────┐  ┌─ Config ──────────┐
│ 1. ENKHBAYAR  ↑↓  │  │ Эхлэх цаг: ___    │
│ 2. BATBAYAR   ↑↓  │  │ Pick: 60s         │
│ 3. NARANBAT   ↑↓  │  │ Cap: 60min        │
│ + бусад тоглогч   │  │ Team: 5           │
└───────────────────┘  └───────────────────┘
                       ┌─ Deploy ──────────┐
                       │ ► DRAFT START     │
                       │ ⟲ RESET ALL       │
                       └───────────────────┘
```

## Алхам алхамаар

### 1. Тоглогчдыг хүлээн авах

Бүх тоглогчид өөрсдөө `/register`-ээр бүртгэгдэнэ. Энэ үед админ нь юу ч хийх шаардлагагүй.

Хэрэглэгчдийн жагсаалтыг `/admin` хуудсын зүүн талын `АХЛАГЧ СОНГОХ` хэсэгт харна.

### 2. Ахлагч сонгох

Хэрэглэгч бүрийн зүүн талын `+` тэмдэгт дарж сонгоно. Сонгогдсон ахлагч `#1`, `#2`, ... гэсэн дугаартай болно.

Snake draft-ийн **эхний pick** нь `#1`-р ахлагч. `↑` `↓` товчоор дарааллыг өөрчилнө.

> **Хамгийн багадаа 2 ахлагч** шаардлагатай. Хамгийн ихдээ 8.

### 3. Draft эхлэх цаг товлох

`Эхлэх цаг (local)` талбарт өөрийн орон нутгийн цагаар бичнэ. Жишээ нь өнөө орой 21:00.

`PICK = 60s`, `CAP = 60min`, `TEAM = 5` нь одоогоор тогтмол утга. Өөрчлөх бол `app/admin/page.tsx`-ийн const-уудыг засна.

### 4. Тохиргоо хадгалах

`ТОХИРГОО ХАДГАЛАХ` → MongoDB-д `status: scheduled` болно.

```json
{
  "status": "scheduled",
  "startAt": "2026-05-07T21:00:00Z",
  "captains": [
    { "userId": "...", "order": 0 },
    { "userId": "...", "order": 1 },
    { "userId": "...", "order": 2 }
  ],
  "teamSize": 5,
  "pickWindowSeconds": 60,
  "totalCapMinutes": 60
}
```

### 5. Draft эхлүүлэх

Цаг болоход `► DRAFT START` товчийг даран draft-ийг идэвхжүүлнэ:

- `status: live` болно
- `endsAt = now + 60min` (нийт cap)
- Эхний ахлагчийн ээлж эхэлж, 60 секундын `turnDeadline` тогтооно
- SSE-ээр бүх клиент шинэчлэгдэнэ

> **Анхаар:** "Start" дарагдсаны дараа буцаах боломжгүй. Зөвхөн `RESET ALL` товчоор бүхэлд нь устгана.

### 6. Хяналт

Draft эхэлсний дараа админ онцгой үйлдэл хийх шаардлагагүй:

- 60 секундэд ээлж сонгоогүй ахлагч **автомат алгасагдана** (server-side reconciliation 1с тутамд хийгддэг).
- 1 цагийн cap-д хүрвэл `status: stopped` болно.

Админ live draft-ыг харахын тулд `/draft` хуудас руу шилжиж болно.

### 7. Reset

Draft дууссны дараа эсвэл хүчингүй болгох бол `⟲ RESET ALL`:

- Бүх picks, captains, time-уудыг арилгана
- Хэрэглэгчид хэвээрээ үлдэнэ (бүртгэл устгагдахгүй)
- `status: idle` болно — шинээр draft эхлүүлж болно

## API эрх

`isAdmin: true` хэрэглэгчид л:

- `PATCH /api/admin/draft`
- `POST /api/admin/draft/start`
- `POST /api/admin/draft/reset`
- `GET /api/admin/users`

рүү хандах эрхтэй. Бусад нь `403`.

## Алгасах механик (snake)

```
Round 1 (forward):  C1 → C2 → C3
Round 2 (reverse):  C3 → C2 → C1
Round 3 (forward):  C1 → C2 → C3
Round 4 (reverse):  C3 → C2 → C1
```

Ахлагч өөрөө slot 1-д автоматаар орох тул `teamSize - 1 = 4` round.

3 ахлагч × 4 round = 12 pick.

Алгасах: `currentTurnIndex` нэмэгдэнэ, тухайн ахлагч одоогийн ээлжээ алдана. Дараагийн round дээрх ээлжүүд хэвийн.

## TIME CAP

`startedAt + totalCapMinutes` хүрвэл шууд `stopped`:

- Бүх draft зогсож, цаашид pick хийх боломжгүй
- Багууд тэр мөч дэх төлөвтөйгөөр үлдэнэ
- Draft зургаар татаж болно
