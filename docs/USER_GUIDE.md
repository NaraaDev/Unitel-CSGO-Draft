# Хэрэглэгчийн зааварчилгаа

## Тоглогчийн ролиуд

Системд гурван үндсэн роль бий:

| Роль | Үүрэг |
|---|---|
| **Тоглогч** (Player) | Бүртгүүлээд тоглогчийн пүүлд орно. Ахлагч сонгох эсэхийг хүлээнэ. |
| **Ахлагч** (Captain) | Админаас сонгогдсон тоглогч. Өөрийн ээлж дээр баг бүрдүүлэхээр сонголт хийнэ. |
| **Админ** | `ADMIN_PHONES`-д бүртгэлтэй дугаартай хэрэглэгч. Цаг товлох, ахлагч сонгох, draft эхлэх / reset хийх эрхтэй. |

> Үзэгчид нэвтрэхгүйгээр `/draft` хуудсаар live харж болно.

## Тоглогчийн flow

### 1. Бүртгүүлэх

`/register` → овог, нэр, утас (8 оронтой), нууц үг (6+ тэмдэгт)

```
┌─────────────────────────────┐
│ Овог:    ENKHBAYAR          │
│ Нэр:     NARANBAT           │
│ Утас:    99112233           │
│ Нууц үг: ••••••••           │
└─────────────────────────────┘
```

Бүртгэгдэнгүүт автоматаар нэвтэрч `/draft` руу шилжинэ.

### 2. Live draft хүлээх

Админ цаг товлоогүй бол `STANDBY`. Цаг товлогдвол `T-MM:SS` countdown гарч ирнэ. Цаг болоход draft `LIVE` болно.

### 3. Ахлагч болсон тохиолдолд

Админ таныг сонгосон бол draft эхлэхэд таны ээлж ирнэ. Хэрэв `currentTurn` дээр өөрийн нэр харагдвал:

- `YOU ARE ON CLOCK` баннер харагдана
- 60 секундын countdown эхэлнэ
- Сул тоглогчдын жагсаалтаас сонгож, картан дээр дарна
- Сонголт хийгдвэл багт автоматаар нэмэгдэнэ

> **Анхааруулга:** 60 секундэд багтаагүй бол ээлж дараагийн ахлагчид шилжинэ. Алгасагдсан pick буцаж ирэхгүй (snake-ийн дагуу үргэлжлэнэ).

### 4. Дууссны дараа

Бүх багт 5 хүн (ахлагч + 4) бүрдвэл `DRAFT FINALIZED`. 1 цаг хэтэрвэл `TIME CAP REACHED`.

`ЗУРГААР ТАТАХ` товчоор багуудыг PNG зургаар татаж авч болно.

## Хайлт ба сонголт хийх

`/draft` хуудсан дээр та өөрийн ээлж дээр:

1. **Хайлт** — `OPERATOR ХАЙЛТ` талбарт нэр / овог бичиж filter хийнэ
2. **Сонголт** — карт дээр дарна. Submit хийгдэх үед `SUBMITTING...` гэж blink хийнэ
3. **Алдаа** — өөр ахлагч таны өмнө нь ижил тоглогчийг авсан бол `409 conflict` гарна. Дараагийн тоглогчийг сонгоно.

## Live харах

Сэргээх хэрэггүй. SSE-р сервэр шууд update илгээдэг.

| Хэсэг | Юу харуулдаг |
|---|---|
| LIVE.OPS panel | Одоогийн ээлжтэй ахлагч + 60s countdown + progress bar |
| TIMECAP panel | Үлдсэн нийт хугацаа (1 цагийн cap) |
| ROSTERS | Багууд, бүх тоглогч өөрийн slot дээрээ |
| PICK_LOG | Бүх pick + skip-ийн түүх |

## Гарах

Толгой хэсэг → `Гарах` товчлуур.
